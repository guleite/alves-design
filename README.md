# Escritório AlvesDesign — landing page (proposta)

Página estática (HTML/CSS/JS) apresentada como proposta de layout pela Concept Agência.

- Configurações no topo de `assets/js/main.js`: `ALVES_WHATSAPP` e `ALVES_LEAD_ENDPOINT` (vazio = o lead só vai para o WhatsApp).
- `robots.txt` e `noindex` bloqueiam indexação enquanto for proposta.
